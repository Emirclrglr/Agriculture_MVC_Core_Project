# Tarım Sitesi Projesi 🌱

Bu proje, tarım sektörüne yönelik temel bir web uygulaması geliştirmek amacıyla oluşturulmuş bir **Tarım Sitesi** eğitim projesidir. Proje, web geliştirme ve modern yazılım teknolojilerini öğrenmek için başlatılmış olup, bazı özellikler eksik veya geliştirilmeye açıktır. Ancak temel işlevsellik ve kullanıcı dostu bir arayüz ile önemli teknolojileri uygulamak hedeflenmiştir.

---

## 🚀 Kullanılan Teknolojiler

Projede, güçlü ve yaygın kullanılan teknolojiler tercih edilmiştir:

- **C#**: Uygulamanın arka planında kullanılan programlama dili. .NET platformu üzerine geliştirilmiştir.
- **N Tier Architecture**: Katmanlı mimari kullanılarak uygulama geliştirilmiştir. Bu yapı, yazılımın modüler, ölçeklenebilir ve bakımı kolay olmasını sağlar.
- **CSS & HTML**: Web sayfasının görsel tasarımı ve yapısı için modern web standartları kullanılmıştır. Responsive tasarım ile farklı cihazlarda uyumlu hale getirilmiştir.
- **ASP.Net Core MVC**: Web uygulamaları geliştirme için kullanılan güçlü bir framework. Model-View-Controller (MVC) mimarisi ile uygulama düzenli bir yapıya kavuşturulmuştur.
- **Identity**: Kullanıcı kimlik doğrulama ve yetkilendirme işlemleri için ASP.NET Core Identity kullanılmıştır.
- **Fluent Validation**: Kullanıcı verilerinin doğruluğunu sağlamak amacıyla veri doğrulama işlemleri için kullanılmıştır.
- **Entity Framework**: Veritabanı işlemleri için kullanılan ORM (Object-Relational Mapping) kütüphanesi. Veritabanı ile etkileşimde kolaylık sağlar.
- **MSSQL**: Veritabanı olarak Microsoft SQL Server kullanılmıştır.

---

## 💻 Proje Özellikleri

Bu proje, aşağıdaki temel özelliklere sahiptir:

- **Kullanıcı Kaydı ve Girişi**: Kullanıcılar sisteme kaydolabilir, giriş yapabilir ve farklı seviyelerde yetkilendirilebilir. 🔑
- **Tarım Ürünleri Yönetimi**: Kullanıcılar, tarım ürünleri hakkında bilgi ekleyebilir, düzenleyebilir ve silebilir. 🌾
- **Kategori Sistemi**: Tarım ürünleri, kategorilere ayrılarak daha kolay erişilebilir hale getirilmiştir. 🏷️
- **Admin Paneli**: Yönetici kullanıcıları, siteyi yönetebilir, ürünleri kontrol edebilir ve kullanıcıları yönetebilir. 🛠️
- **Responsive Tasarım**: Uygulama, mobil uyumlu ve farklı cihazlarda düzgün çalışan bir tasarıma sahiptir. 📱💻
